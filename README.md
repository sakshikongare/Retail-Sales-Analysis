## Project Overview
The Retail Sales Analysis Dashboard is a data analytics project developed using Microsoft Power BI. It helps analyze retail sales data and convert raw data into meaningful business insights through interactive visualizations.

## Objectives
- Analyze overall retail sales performance.
- Identify top-performing product categories.
- Track monthly sales trends.
- Compare sales across cities or regions.
- Analyze quantity sold and profitability.
- Monitor inventory levels when inventory data is available.
- Support data-driven business decisions.

## Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV / Excel datasets

## Dashboard Features
- KPI cards for Total Sales, Total Profit, Total Quantity, and Total Transactions, depending on available data.
- Monthly sales trend analysis.
- Product category performance analysis.
- City-wise or regional sales comparison.
- Interactive filters for dates, categories, cities, and sales channels where available.
- Inventory and stock-risk analysis if inventory data is included.

## How to Use
1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the Power BI dashboard (.pbix) file.
4. Update the dataset path if required.
5. Refresh the data.
6. Explore the dashboard using interactive filters and charts.
